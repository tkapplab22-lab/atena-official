プライバシーポリシー

「あてな！」における利用者情報の取扱いについて定めるものです。

TAKAHIKO KAWAMOTO（以下「運営者」といいます。）は、ゲームアプリ「あてな！」（以下「本サービス」といいます。）における利用者情報の取扱いについて、次のとおり定めます。

第1条　取得する情報

運営者は、本サービスの提供に必要な範囲で、次の情報を取得または保存します。

  • Firebase Authenticationにより発行される認証用識別子（Firebase UID）
  • 本サービス内で発行されるPLAYER ID
  • 利用者が設定するplayerName（ゲーム内表示名）
  • ランク、RP、勝敗、連勝数、最少CALL勝利等の戦績
  • 選択キャラクター、PERK編成、COINその他のゲーム進行情報
  • マッチメイキングおよびオンライン対戦の進行に必要な参加者情報、対戦状態、公開イベントその他の関連情報
  • 広告の表示、同意管理、広告効果測定および不正防止のためにGoogleのSDKが取得する端末情報、広告操作情報、概略的な位置情報、診断情報、識別子等
  • BGM、SE、VOICE、HAPTICS、チュートリアル完了状態、キャラクター・PERK選択、広告表示間隔等、端末内に保存される設定情報

第2条　利用目的

取得した情報は、次の目的で利用します。

  • アカウントの作成、認証、引継ぎおよび管理
  • 本サービスの提供、ゲーム進行、対戦、マッチメイキング、ランキングおよび戦績表示
  • 利用者ごとの設定、キャラクター、PERKその他の状態の保存と復元
  • 広告の配信、広告に関する同意の管理、広告の品質確保および不正防止
  • 不具合、障害、不正利用その他の問題の調査と対応
  • お問い合わせへの対応
  • 本サービスの安全性、利便性および品質の維持・改善

第3条　利用する外部サービス

本サービスでは、Google LLCが提供する次のサービスを利用します。各サービスによる情報の取扱いには、同社が定める規約およびプライバシーポリシーが適用されます。

  • Firebase Authentication：利用者認証
  • Cloud Firestore：プロフィール、ゲーム進行情報および戦績等の保存
  • Firebase Realtime Database：マッチメイキングおよびオンライン対戦状態の同期
  • Google AdMob：広告配信
  • Google User Messaging Platform（UMP）：広告に関する同意情報の取得および管理

第4条　広告と同意管理

本サービスはGoogle AdMobによる広告を表示することがあります。対象地域その他の条件に応じて、Google User Messaging Platform（UMP）を通じて広告に関する選択肢を提示します。プライバシー設定の再確認が必要な場合は、SETTINGS内の「プライバシー設定」から変更できます。広告SDKが取り扱う情報や選択肢の内容は、利用地域、端末設定、同意状態およびGoogleの設定等により異なる場合があります。

第5条　PLAYER IDとplayerName

PLAYER IDは、本サービス内で利用者を識別するために発行されます。playerNameは利用者が設定するゲーム内表示名であり、対戦相手その他の利用者に表示される場合があります。氏名、連絡先その他の個人情報をplayerNameとして設定しないようご注意ください。

第6条　SECRET CODEの取扱い

対戦時に利用者が設定する3桁のSECRET CODEは、現在の設計では対戦フロー中のメモリ内でのみ一時的に保持し、UserDefaults、ファイル、Cloud FirestoreまたはFirebase Realtime Databaseの相手方から直接読み取れる共有領域へ恒久保存しません。また、意図的なログ送信の対象としません。

第7条　第三者への提供

運営者は、法令に基づく場合、利用者または第三者の生命・身体・財産等を保護するために必要な場合、または本ポリシーに記載した外部サービスの利用に必要な場合を除き、利用者情報を第三者へ提供しません。外部サービス事業者には、そのサービス提供に必要な範囲で情報が送信される場合があります。

第8条　情報の管理と保存期間

運営者は、利用者情報への不正アクセス、漏えい、改ざん、紛失等を防ぐため、合理的な安全管理措置を講じます。情報は、本サービスの提供、法令上の義務、紛争対応その他の正当な目的に必要な期間保持し、その必要がなくなった情報は適切な方法で削除または匿名化します。端末内設定は、アプリの削除や端末の操作により消去される場合があります。

第9条　アカウントの削除

本サービスでは、利用者がアプリ内のアカウント削除機能からアカウントの削除を行える機能を提供します。削除手続が完了すると、認証情報および当該アカウントに紐づくプロフィールやゲームデータを削除します。ただし、法令上の保存義務、不正利用の防止、セキュリティ確保、紛争対応その他の正当な理由がある情報については、必要な範囲と期間に限り保持する場合があります。

第10条　利用者の選択とお問い合わせ

利用者は、端末または本サービスの設定を通じて、一部の設定や広告に関する選択を変更できます。保有情報の取扱い、訂正、削除その他のご相談は、本ポリシー末尾の問い合わせ先へご連絡ください。本人確認その他の必要な確認をお願いする場合があります。

第11条　本ポリシーの変更

運営者は、本サービスの内容、利用するサービスまたは適用法令の変更等に応じて、本ポリシーを変更することがあります。重要な変更がある場合は、本サービス内その他の適切な方法でお知らせします。

第12条　準拠法令

運営者は、日本の個人情報の保護に関する法律その他、本サービスに適用される法令を踏まえて利用者情報を取り扱います。
